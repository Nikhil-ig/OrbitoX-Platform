### PHASE 1: CORE CANVAS & SELECTION/TRANSFORM ENGINE
**Goal**: Deliver rock-solid, Figma-grade direct manipulation on the artboard.
- **Tasks**:
  1. Pass `onNodeClick` directly from `CanvasWorkspace.tsx` through `<SceneGraphRenderer>` to ensure all DOM elements reliably trigger `onSelectNode()`.
  2. Implement `Cmd` / `Ctrl` + Click deep selection to bypass parent frames and select leaf nodes.
  3. Implement Marquee drag-selection on the canvas overlay with bounding-box intersection calculations.
  4. Build dynamic Smart Alignment Guides with magenta axis lines and numerical spacing badges during pointer dragging.
  5. Upgrade `CanvasInteractionLayer` to distinguish between `position: 'flow'` (rendering insertion line indicators) and `position: 'absolute'` (updating X/Y coordinates).
  6. Implement Zoom-to-Cursor math so zooming anchors directly to the mouse pointer.
  7. Add multi-select group bounding box calculation and transform handles.

---

### PHASE 2: REAL TEMPLATE & SECTION ENGINE
**Goal**: Make template switching and section building completely reliable, non-destructive, and deterministic.
- **Tasks**:
  1. Build `TemplateContentMigrator`: Extracts existing customer content (`names`, `dates`, `photos`, `story`, `rsvp`) and injects it into matching slots of incoming templates.
  2. Enforce atomic page-scene synchronization in `TemplateEditorStore.ts`: `INSERT_SECTION`, `REMOVE_SECTION`, `MOVE_SECTION`, and `DUPLICATE_SECTION` update `draft.scenes[]` and `draft.pages[activePage].sectionIds[]` in a single transaction.
  3. Build recursive UUID re-generator for `DUPLICATE_SECTION` to prevent key collisions.
  4. Add Section Variant switcher (e.g. swap Hero layout between Minimalist, Split Editorial, and Fullscreen Video without losing copy).
  5. Build visual Section Reorder Tray in the left rail for frictionless drag-and-drop page restructuring.

---

### PHASE 3: ASSET STUDIO & MEDIA PIPELINE
**Goal**: Seamless media management with instant drag-and-drop canvas replacement.
- **Tasks**:
  1. Upgrade `AssetsPanel.tsx` with unified search, category tabs (Photos, Graphics, Backgrounds, Audio), and folder management.
  2. Implement HTML5 Drag-and-Drop: Dragging an image from the asset tray onto an existing canvas `image` node highlights the node and replaces `props.src` on drop.
  3. Implement automated client-side image compression (converting high-res PNG/JPEG to optimized WebP Data URLs or signed cloud storage URLs).
  4. Add visual Aspect Ratio and Focal Point picker in the Image Inspector.

---

### PHASE 4: FIGMA-GRADE MASTER COMPONENTS & OVERRIDES
**Goal**: True reusable design system components with instance override tracking.
- **Tasks**:
  1. Add `masterComponents: Record<string, SceneGraphNode>` to `TemplateSchema`.
  2. Implement "Create Component" action: moves node tree to master registry, replaces canvas node with an Instance node (`kind: 'instance'`, `masterId: '...'`).
  3. Support isolated property overrides on instances (Text content, Button URL, Image fill).
  4. Add visual Component Inspector controls: "Reset Overrides" and "Push Changes to Master".

---

### PHASE 5: RESPONSIVE CASCADE & MOTION ENGINE
**Goal**: Production Webflow-level responsive cascade and Framer-grade spring physics.
- **Tasks**:
  1. Implement Breakpoint Cascade inheritance: Desktop values cascade to Tablet (768px) and Mobile (390px).
  2. Add visual inheritance badges in `PropertiesPanel.tsx` (showing blue badge when a property has been overridden on mobile).
  3. Build interactive visual Margin/Padding Box Model in the inspector with drag-to-adjust handles.
  4. Enhance `MotionWorkspace.tsx` with Spring Physics sliders (`damping`, `stiffness`, `mass`) and a visual cubic-bezier curve editor.
  5. Implement scroll-linked parallax depth planes (`-5` to `+5`) in `SceneGraphRenderer`.

---

### PHASE 6: AI DESIGNER CORE & PRODUCTION EDGE PUBLISHING
**Goal**: Conversational design intelligence mutating real AST nodes, and one-click edge deployment.
- **Tasks**:
  1. Build `AIDesignEngine.ts`: Translates natural language prompts into atomic SceneGraph commands (Theme swapping, typography pairing, layout restructuring).
  2. Implement atomic single-step undo for AI operations (a single `Cmd + Z` cleanly rolls back the entire AI redesign).
  3. Connect Publishing Modal to `@orbitox-io/plugin-engine` license validator and custom domain DNS verification.
  4. Generate optimized, clean static production HTML/CSS with automated OpenGraph tags and schema.org structured data.

## 4. MIGRATION & BACKWARD COMPATIBILITY STRATEGY

1. **Schema Versioning (`schemaVersion: 2`)**:
   - Existing saved projects in LocalStorage or database are marked with `schemaVersion: 1`.
   - On initial load, `TemplateSchemaService.upgradeSchema()` checks version:
     - Automatically backfills empty `masterComponents: {}`.
     - Synthesizes `responsiveOverrides: {}` for older nodes lacking breakpoint data.
     - Ensures all sections present in `draft.scenes[]` are registered in `activePage.sectionIds[]`.
2. **Zero Downtime / Zero Data Loss Guarantee**:
   - The migration runs entirely client-side in memory before store initialization.
   - A backup of the legacy schema is preserved under `localStorage.getItem('orbitox_backup_v1_${slug}')`.

## 5. RISK ASSESSMENT & MITIGATION MATRIX

| Risk Factor | Probability | Impact | Mitigation Strategy |
|---|:---:|:---:|---|
| **Performance with Large DOM Trees** (500+ nodes) | Medium | High | Implement viewport virtual scrolling: off-screen sections unmount heavy interactive overlays and render lightweight static placeholders. |
| **Undo/Redo Memory Overhead** | Low | Medium | Limit history stack to 50 deep clones; throttle slider change events so history frames only push on `pointerup`. |
| **CSS Flex vs Absolute Drag Ambiguity** | High | High | Explicit visual indicator during drag: if dragging inside a flex frame, render blue insertion guide lines; if holding `Alt`, toggle node to `position: 'absolute'`. |
| **Data Loss on Template Switch** | Medium | Critical | `TemplateContentMigrator` strictly parses and ports all existing bound fields before applying new schema. If any slot fails, prompt user with preview diff dialog. |
| **Third-Party Script Hydration Conflicts** | Low | Low | Isolate 3D WebGL (Three.js) and Lottie runtimes in sandbox container layers with clean unmount lifecycles. |
