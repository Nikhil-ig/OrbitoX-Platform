## 1. Executive Summary & Philosophy Shift

Phase P16.1 successfully established the foundational architecture:
- 6 core subsystems unified under the `StudioShell`
- Deterministic unidirectional data store (`TemplateEditorStore`)
- SceneGraph Virtual DOM renderer (`SceneGraphRenderer`)

A creator does not evaluate a design tool by inspecting test assertions; they evaluate it by opening a template, changing a heading, dragging a section, modifying a mobile layout, previewing motion, and seeing that **their exact published website renders identically to what they designed**.

### Critical Findings & Broken Workflows Identified:

| Step | Workflow Stage | Current Behavior | Gap / Broken Experience | Severity |
| :--- | :--- | :--- | :--- | :--- |
| **19** | **Open Real Website** | In `StudioPublishModal.tsx`, clicking deploy generates `https://orbitox.site/[slug]` (external, unreachable in local dev). In local route `/e/[slug]`, the page loads `localStorage.getItem('orbitox_exp_[slug]')` which is the **old legacy ExperienceView**, completely ignoring `orbitox_celebrations_template_schema_[slug]`. | **CRITICAL BREAK**: The published website displays a hardcoded demo wedding and NONE of the designer's work from Studio Zero is rendered. | 🔴 Blocker |
| **2** | **Template Switching** | `handleReplaceSite` migrates text/image slots via `TemplateContentMigrator`, but URL query parameter `?template=` is not synchronized. | Pressing browser reload (F5) re-fetches the initial URL template slug, reverting user's switch. | 🟠 High |
| **6** | **Add Sections** | `handleAddTemplateSection` takes the first scene of a template and adds it to the project. | Scene node IDs are not recursively re-keyed upon insertion. Adding two sections from the same template creates duplicate node ID collisions. | 🟠 High |
| **7** | **Section Reordering** | In `PagesPanel.tsx`, HTML5 drag handle triggers `onReorderSections`, which calls `controller.dispatch({ type: 'REORDER_SCENES' })`. | In the continuous canvas workspace, dragging sections vertically via canvas handle does not always update canvas viewport scroll offsets smoothly. | 🟡 Medium |
| **8** | **Element Editing** | Basic elements (text, button, image, container) update style and geometry. | Specialized elements (Countdown, Map/Venue, Form, 3D Canvas) have limited direct visual editing handles in `PropertiesPanel` compared to basic elements. | 🟡 Medium |
| **10** | **Component System** | `createMasterComponent` and `instantiateComponent` exist. Overrides work per instance. | When a master component's children are modified on canvas, instance synchronization requires manual "push to master" or full store re-resolution. | 🟡 Medium |
| **12** | **Motion Preview** | Motion workspace edits spring physics and bezier curves, saved into `node.motion`. | In `/e/[slug]` (real website), because `SceneGraphRenderer` was not mounted, runtime animations never fired for the public visitor. | 🔴 Blocker |
| **17** | **Save & Persistence** | Autosave writes to `localStorage` with prefix `orbitox_celebrations_template_schema_`. | If local storage quota is exceeded due to embedded base64 assets, save fails silently without recovery toast. | 🟠 High |

## 3. Deep Workflow Acceptance Audit (13 Domains)

### 3.1. Template System Determinism (10 Required Archetypes)
**Required Test**:
```text
Celestial ➔ Editorial ➔ Minimal ➔ Botanical ➔ Noir ➔ Aurora ➔ SaaS ➔ Portfolio ➔ Ecommerce ➔ 3D
```
- **Current State**:
  - `BUILTIN_SCHEMAS` in `builtin-schemas.ts` holds: `celestial-odyssey`, `minimal-editorial`, `floral-romance`, `modern-harmony`, `amalfi-riviera`, `party-nocturne`, `romantic-doors`, `royal-regalia`, `surreal-organimo`.
  - `TemplateBrowserModal.tsx` contains 13 industry templates (including `tmpl-saas-cloudpulse`, `tmpl-portfolio-mono`, `tmpl-ecommerce-lumina`, `tmpl-agency-kinetic`).
- **Gaps**:
  - `TemplateBrowserModal` relies on `TemplateFactory.createModernTemplate` for SaaS/Portfolio/Ecommerce. We must guarantee that all 10 archetypes have rich, dedicated SceneGraphs with production layouts, typography, and default assets.
  - Test case `Template A -> Replace with Template B -> Add section from Template C -> Apply Theme D` must be deterministically tested with automated verification of node ID uniqueness, slot mapping, and token integrity.

### 3.2. Real Section Composer
**Required Test**:
```text
Initial: Hero, Features, Gallery, Testimonials, Footer
➔ Insert Pricing (becomes Hero, Features, Pricing, Gallery, Testimonials, Footer)
➔ Drag Gallery above Hero (becomes Gallery, Hero, Features, Pricing, Testimonials, Footer)
➔ Undo (restores previous state exactly)
```
- **Current State**:
  - `WebSectionLibrary.ts` has `buildPricingTableScene`, `buildHeroCenteredScene`, `buildFeatureGridScene`, `buildTestimonialsScene`, `buildFooterScene`.
  - `CanvasWorkspace` and `PagesPanel` support inserting at index, moving up/down, and drag reordering.
  - `TemplateEditorStore` handles `ADD_SECTION`, `MOVE_SECTION`, `REORDER_SCENES`, and `UNDO`.
- **Gaps**:
  - Verified that `REORDER_SCENES` correctly mutates draft with history push. We need an end-to-end user-level test verifying that DOM ordering in `#orbitox-artboard-frame` exactly matches `schema.scenes` indices in both canvas and preview mode.

### 3.3. Element Authoring Freedom (15 Major Elements)
**Required Elements**:
`Text`, `Heading`, `Image`, `Video`, `Button`, `Icon`, `Shape`, `Container`, `Stack`, `Grid`, `Gallery`, `Form`, `Countdown`, `Map`, `3D`.
- **Current State**:
  - `PrimitiveNodeKind` supports: `frame`, `container`, `stack`, `grid`, `text`, `richtext`, `image`, `video`, `audio`, `shape`, `line`, `button`, `icon`.
  - `SemanticNodeKind` supports: `countdown`, `venue` (Map), `gallery`, `rsvpform` (Form).
  - Node adapters in `BasicNodeAdapters.tsx`, `AdvancedNodeAdapters.tsx`, and `SmartNodeAdapters.tsx` render each kind.
- **Gaps**:
  - Selection, Move, Resize, Style, Duplicate, Delete, Undo, Redo, Save, Reload must be verified for **all 15 elements** without rendering anomalies.
  - Dedicated inspector controls in `PropertiesPanel` for Countdown (target date/style), Form (inputs/submit action), Map (lat/lng/pins), and 3D (mesh/rotation).

### 3.4. Real Asset Pipeline
**Required Asset Types**:
`Images`, `Videos`, `Audio`, `SVG`, `Fonts`, `Lottie`, `Rive`, `3D Models`, `3D Scenes`.
- **Current State**:
  - `AssetsPanel.tsx` supports category tabs: `photos`, `graphics` (SVG), `backgrounds`, `video`, `audio`, `uploads`.
  - `FileUploadService.ts` handles client-side image compression to WebP with LQIP thumbnail generation.
  - Dragging asset onto image nodes replaces `url`.
- **Gaps**:
  - Need dedicated UI tabs and drop handlers in `AssetsPanel` for:
    - **Fonts** (`.woff2`, `.ttf`) with dynamic `@font-face` injection.
    - **Lottie / Rive** (`.json`, `.riv`) with runtime player node adapter.
    - **3D Models** (`.gltf`, `.glb`) with Three.js loader node adapter.
  - Quota management: Warn creator when base64 asset payload exceeds `localStorage` safe threshold (4.5MB), offering local IndexedDB asset storage fallback.

### 3.5. Design Universes & Theme System
**Required Test**:
`Theme A -> Apply -> actual site changes. Theme B -> Apply -> original content remains. Colors, Typography, Spacing, Radius, Shadows, Effects, Motion, Components update.`
- **Current State**:
  - `DesignUniverseEngine` holds 12 universes: Celestial, Minimal, Botanical, Cyber, Luxury, Editorial, Noir, Aurora, Glassmorphism, Retro, Monocle, Brutalist.
  - `handleApplyUniverse` updates `schema.designTokens`.
  - Content nodes bind styles to tokens via `{ type: 'token', tokenPath: 'colors.textPrimary' }`.
- **Gaps**:
  - Verify that nodes with inline hardcoded hex colors (`#FFFFFF`) do not block theme switching; provide a "Re-link to theme tokens" option in `PropertiesPanel`.

### 3.6. Typography Studio
**Required Test**:
`Font Pairing -> Apply -> visible typography changes -> responsive typography preserved -> save -> reload.`
- **Current State**:
  - `TypographyStudio.ts` defines 8 curated pairings with Google Font stylesheets.
  - `StylesPanel.tsx` allows 1-click application.
- **Gaps**:
  - Dynamic font loading: When a user selects a custom Google Font or uploads a local font, ensure `<link>` or `@font-face` is injected into both the editor canvas `<iframe>`/wrapper and the published HTML bundle in `ProductionEdgeExporter`.

### 3.7. Component Architecture (Master / Instance / Overrides / Detach)
**Required Test**:
`Navbar master -> 5 instances. Change master -> all 5 update. Override one instance -> only that instance changes. Detach -> that instance becomes independent.`
- **Current State**:
  - Supported in `TemplateEditorStore`: `SG_CREATE_COMPONENT`, `SG_INSTANTIATE_COMPONENT`, `SG_SET_INSTANCE_OVERRIDE`, `SG_RESET_INSTANCE_OVERRIDES`, `SG_PUSH_INSTANCE_TO_MASTER`, `SG_DETACH_INSTANCE`.
  - `ComponentsPanel.tsx` displays master components and instance status.
- **Gaps**:
  - Verify that when a master component node is edited directly in the canvas (e.g., text or color), all child instances in other scenes update reactively without requiring a manual store restart.

### 3.8. Responsive Art Direction
**Required Test**:
`Desktop (Image | Content) -> Tablet (Image \n Content) -> Mobile (Image \n Content \n CTA). Change desktop -> inheritance. Change mobile -> desktop remains unchanged.`
- **Current State**:
  - `StyleResolver.ts` implements cascading inheritance: `desktop` -> `tablet` -> `mobile`.
  - `PropertiesPanel.tsx` checks `activeViewport` and saves overrides to `node.responsive[activeViewport]`.
- **Gaps**:
  - Add visual indicator ("Inherited from Desktop" vs "Overridden on Mobile") on individual property input fields in `PropertiesPanel` so designers clearly know which properties are customized for mobile.

### 3.9. Motion & Parallax Runtime
**Required Test**:
`Heading -> Cinematic Reveal. Image -> Depth Zoom. Background -> Parallax. CTA -> Spring. Preview & Real Website parity.`
- **Current State**:
  - `MotionWorkspace.tsx` provides Spring physics simulation, Bezier curve visualizer, and 7 presets.
  - Stored in `node.motion.in` and `node.motion.scroll`.
- **Gaps**:
  - `SceneGraphRenderer` executes CSS animations on hover and scroll. Ensure that when published, `ProductionEdgeExporter` compiles full CSS keyframes for `cinematic-reveal`, `depth-zoom`, and parallax scroll listeners.

### 3.10. Cinematic Narrative Experience
**Required Test**:
`Multi-scene narrative: Scene 1 Arrival, Scene 2 Reveal, Scene 3 Journey, Scene 4 Immersion. Scroll camera movement, parallax, atmospheric effects.`
- **Current State**:
  - `CelestialOdyssey` and `AtmosphericCanvas` provide particle fields, astrolabe rings, and star maps.
- **Gaps**:
  - Ensure seamless scene-to-scene scroll transitions with intersection observer triggers across continuous vertical flow.

### 3.11. 3D Spatial Computing & WebGL
**Required Test**:
`3D Model + Camera + Lighting + Material + Animation + Scroll interaction in Studio, Preview, and Published Website.`
- **Current State**:
  - `ThreeDWorkspace.tsx` has interactive canvas renderer with wireframe orbital rings and particles.
  - `surreal-organimo` template has 3D spatial definitions.
- **Gaps**:
  - Standalone 3D canvas node adapter for the main artboard flow so 3D objects can sit inside any standard section (e.g. Hero or Product Showcase).

### 3.12. Real-World Performance Health Audit
**Required Test**:
`Calculate: DOM nodes, Asset size, JS size, CSS size, Video size, 3D runtime, GPU effects, Animation count, LCP, CLS, INP across Desktop, Tablet, Mobile based on actual project data.`
- **Current State**:
  - `PerformanceModal.tsx` displays calculated score, total nodes, image/video weight KB, animation tracks, and FPS.
- **Gaps**:
  - Replace static heuristic formulas with live document measurements:
    - DOM count: `document.querySelectorAll('*').length`
    - Asset weight: Sum of actual `ProjectAsset.sizeBytes` in schema
    - CSS weight: Size of generated stylesheet from `ProductionEdgeExporter`
    - Estimated Core Web Vitals (LCP, CLS, INP) based on image count above fold and uncompressed fonts.

### 3.13. Error Recovery & Disaster Resilience
**Required Test**:
`Failures tested: Asset upload fails, Template load fails, Network disconnects, Publish fails, AI request fails, Font fails. Recovery: Save draft, Local recovery, Server recovery, Version history, Undo, Retry, Rollback.`
- **Current State**:
  - Auto-save debounced with status (`saving`, `saved`, `error`).
  - `TemplateSchemaService` has fallback recovery for corrupted scene graphs.
- **Gaps**:
  - Add explicit error boundaries around canvas sections so an invalid custom node does not crash the entire editor studio.
  - Add a dedicated "Restore from Version History / Emergency Draft" action in `StudioTopBar`.

- **Target**: Recursively traverse `sceneGraph.nodes`, assign new UUIDs (`node_${Date.now()}_${rand}`), and update parent/child pointer arrays to guarantee zero node ID collisions when recombining templates.

### Fix D: Master Component Instant Canvas Reactivity

- **Target**: When modifying a master component's geometry or style, automatically update the default presentation of all instances across all scenes that do not have explicit instance overrides for that property.

- **Target**: Compute real DOM node count, actual asset byte size from `schema.assets`, compiled CSS byte size, and Core Web Vitals estimates per breakpoint.
