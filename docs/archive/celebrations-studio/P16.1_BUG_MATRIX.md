## 2. ROOT CAUSE SUMMARY & PREVENTION ARCHITECTURE

All identified failures stem from three root causes:
1. **Event Propagations Gaps**: UI presentation layer (e.g. `SceneGraphRenderer`) missing callback props connecting user gestures to store commands.
2. **Dual-Truth Invariant Violations**: Two data structures representing the same relationship (e.g. `draft.scenes[]` vs `activePage.sectionIds[]`) mutating independently rather than atomically in a single reducer transaction.
3. **Destructive State Overwrites**: Global operations (e.g. template switching) discarding user content instead of running non-destructive semantic migrators.

By enforcing the **Single Canonical Project AST**, **Atomic Reducer Invariants**, and **Event-Driven CQRS Architecture**, every bug in this matrix is systematically eliminated at the architectural level.
