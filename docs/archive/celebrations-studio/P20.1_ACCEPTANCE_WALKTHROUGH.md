## 2. Core Architectural Pillars & Enhancements

### 2.1 Deterministic ID Allocation & Pure Reducers
- **Problem Solved:** Previously, reducers generated non-deterministic random IDs (`Math.random()`), violating Redux/Immer purity and breaking state replay or CRDT synchronization.
- **P20.1 Implementation:**
  - Built `IdAllocator.ts` with `allocateSceneId()`, `allocateNodeId()`, and `rekeyScene()`.
  - The controller (`TemplateEditorController.tsx`) deterministically allocates all IDs **before** dispatching actions.
  - Reducers in `TemplateEditorStore.ts` are 100% pure side-effect-free state transitions.

### 2.2 Published Runtime Parity for 3D & Motion
- **Problem Solved:** Studio 3D and Motion previously ran only inside isolated studio tabs; published guest links (`/e/[slug]`) and preview modals rendered flat static content.
- **P20.1 Implementation:**
  - Created `ThreeDRuntimeNode.tsx` using Three.js WebGL 2.0, directional/ambient lighting, and PBR materials.
  - Registered `threed` and `model3d` in `AdvancedNodeAdapters.tsx`.
  - Created `MotionRuntimeNode` inside `SceneGraphRenderer.tsx` driving hardware-accelerated WAAPI keyframe animations at 60 FPS in published guest runtimes.

### 2.3 Direct Blueprint Access in TemplateSchemaService
- **Problem Solved:** Direct URL access to non-wedding templates previously fell back to wedding defaults due to missing catalog resolution.
- **P20.1 Implementation:**
  - Integrated `BLUEPRINT_CATALOG` into `TemplateSchemaService.ts`.
  - Loading `/admin/template-studio?template=saas-nextgen` or `/e/saas-nextgen` resolves directly to authentic multi-vertical blueprints with complete section and node hierarchies.

## 3. Real Creator Journey Verification

The system was evaluated against 5 full-scale creator workflows in `tests/e2e/creator-journeys.spec.ts`:

1. **JOURNEY-01: Create from SaaS Template Full Workflow**
   - Loads SaaS NextGen blueprint.
   - Edits hero title and button CTA on canvas.
   - Adjusts responsive breakpoints (Desktop -> Tablet -> Mobile).
   - Verifies canvas dimension reflow and node selection.
   - Persists state cleanly.

2. **JOURNEY-02: Blank Canvas Multi-Section Composition**
   - Starts with empty document.
   - Adds 3 sequential sections (Header, Hero, Pricing) via `IdAllocator`.
   - Reorders sections in the PageTree document tree.
   - Verifies deterministic section IDs and canvas order updates.

3. **JOURNEY-03: Asset Pipeline & IndexedDB Binary Storage**
   - Ingests high-resolution images and videos into IndexedDB.
   - Generates instantaneous Blob URLs for preview.
   - Verifies zero browser freezing, zero schema bloat, and instant rehydration on reload.

4. **JOURNEY-04: Cinematic Spatial 3D & WAAPI Motion Runtime**
   - Inserts 3D canvas node with metallic PBR mesh.
   - Configures WAAPI spring entrance animations.
   - Verifies Three.js WebGL rendering and 60 FPS motion execution in `SceneGraphRenderer`.

5. **JOURNEY-05: Multi-Vertical Semantic Template Switching**
   - Switches between Wedding, SaaS, Agency, and Commerce templates.
   - Preserves semantic slots (brand, headline, CTA) without data clobbering.
   - Cleans up orphaned DOM nodes with zero NaN coordinate errors.
