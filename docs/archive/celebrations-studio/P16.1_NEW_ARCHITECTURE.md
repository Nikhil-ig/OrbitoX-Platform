## 2. SUBSYSTEM SPECIFICATIONS

### 2.1 STUDIO SHELL
The top-level shell coordinates multi-pane docking, modal overlays, tool modes, and persistent keyboard event listeners.
- **Modes**:
  - `edit`: Default visual composer with canvas artboard and panels.
  - `motion`: Bottom timeline docked for keyframe and spring animation authoring.
  - `3d`: Full spatial viewport with orbit controls and lighting shaders.
  - `prototype`: Interactive simulation honoring click interactions and page navigation.
  - `preview`: Fullscreen responsive preview mimicking production deployment.
- **Top Bar**: Viewport switcher (Desktop 1440, Tablet 768, Mobile 390), Zoom controller (Fit, 50%, 100%, 200%), Undo/Redo stack counter, AI Assistant launcher, and Publish modal.

### 2.2 CANVAS ENGINE & SELECTION/TRANSFORM ENGINE

#### 2.2.1 Hit-Testing & Selection Physics
- **Click Selection**: Single click selects top-level element.
- **Double Click**: Enters text editing mode (`InlineEditOverlay`) for text nodes, or drills down one level into child containers.
- **Deep Selection (`Cmd` / `Ctrl` + Click)**: Pierces through all parent frames and directly selects the leaf node under cursor.
- **Marquee Drag Selection**: Dragging pointer on empty canvas creates an animated selection rectangle. Computes geometric intersection against node bounding boxes; selects all intersecting nodes.
- **Shift + Click**: Toggles selection membership (multi-select).
- **Parent/Child Traversal**: Pressing `Escape` selects immediate parent. Pressing `Enter` selects first child.

#### 2.2.2 Transform Controls & Smart Guides
- **8 Resize Handles**: Top-left, top-center, top-right, middle-left, middle-right, bottom-left, bottom-center, bottom-right.
  - Shift-drag: Constrains aspect ratio.
  - Alt/Option-drag: Resizes symmetrically about center.
- **Rotation Stem**: Top center handle extending 20px above bounding box. Dragging rotates element with 15° snapping when Shift is held.
- **Smart Alignment Guides**:
  - Real-time comparison between active node rect and sibling rects.
  - Renders magenta guide lines when aligned to sibling edges or center.
  - Calculates spacing between consecutive elements; renders distance badges (`16px`, `24px`).
- **Positioning Engine**: Distinguishes between:
  - `position: 'flow'` (Flex/Grid child): Dragging triggers visual reorder insertion drop-indicators rather than absolute X/Y coordinate mutation.
  - `position: 'absolute'`: Dragging updates explicit `geometry.x` and `geometry.y`.

#### 2.2.3 Universal Keyboard Shortcuts
| Shortcut | Action |
|---|---|
| `Cmd + Z` / `Ctrl + Z` | Undo last command |
| `Cmd + Shift + Z` / `Ctrl + Y` | Redo command |
| `Arrow Keys` | Nudge selected element by 1px |
| `Shift + Arrow Keys` | Nudge selected element by 10px |
| `Backspace` / `Delete` | Delete selected node(s) |
| `Cmd + D` / `Ctrl + D` | Duplicate selected node(s) with 20px offset |
| `Cmd + C` / `Cmd + V` | Copy / Paste node subtree to clipboard |
| `Cmd + [` / `Cmd + ]` | Send backward / Bring forward in layer stack |
| `Cmd + G` / `Cmd + Shift + G` | Group selected nodes into Frame / Ungroup |
| `Spacebar + Drag` | Pan canvas |
| `Cmd + Wheel` | Zoom canvas centered at cursor coordinates |

### 2.3 SCENEGRAPH CORE

#### 2.3.1 Canonical Node Data Model
Every element in OrbitoX Studio conforms to the normalized `SceneGraphNode` AST:
```typescript
interface SceneGraphNode {
  id: string;                          // Unique UUID
  kind: SceneNodeKind;                 // 40+ supported primitive & composite types
  name: string;                        // Human-readable layer label
  parentId: string | null;             // null if root section artboard
  children: string[];                  // Ordered list of child node IDs
  
  geometry: {
    x: number;
    y: number;
    width: number | 'auto' | '100%';
    height: number | 'auto' | '100%';
    rotation: number;                  // Degrees (0-360)
    opacity: number;                   // 0.0 to 1.0
    zIndex: number;
    position: 'flow' | 'absolute' | 'sticky' | 'fixed';
  };
  
  layoutMode: 'flow' | 'flex' | 'grid' | 'freeform';
  layoutConfig?: {
    direction?: 'row' | 'column';
    justify?: 'flex-start' | 'center' | 'flex-end' | 'space-between';
    align?: 'flex-start' | 'center' | 'flex-end' | 'stretch';
    gap?: number;
    padding?: { top: number; right: number; bottom: number; left: number };
    wrap?: boolean;
  };
  
  style: {
    typography?: TypographyStyle;
    background?: BackgroundStyle;      // Solid, linear-gradient, radial-gradient, image
    border?: BorderStyle;              // Width, style, color, individual corner radiuses
    shadows?: BoxShadowStyle[];
    filters?: FilterStyle;             // Blur, backdrop-filter, grayscale, brightness
  };
  
  responsive: {
    tablet?: Partial<NodeGeometry & NodeStyle & LayoutConfig>;
    mobile?: Partial<NodeGeometry & NodeStyle & LayoutConfig>;
  };
  
  motion?: {
    preset?: string;                   // 'fade-up', 'zoom-in', 'spring-bounce'
    duration?: number;
    delay?: number;
    easing?: string;
    parallaxDepth?: number;            // -5 to +5 for scroll depth planes
  };
  
  interactions: NodeInteraction[];     // OnClick, OnHover, OpenModal, ScrollTo, Navigate
  binding?: {
    fieldKey: string;                  // e.g. "celebrant.name", "event.date"
    fallback: string;
  };
  
  component?: {
    masterId?: string;                 // If instance, references master component
    overrides?: Record<string, any>;   // Specific property overrides
  };
  
  locked: boolean;
  hidden: boolean;
  smartProps: Record<string, any>;     // Type-specific properties (countdown target, map coords)
  textContent?: string;
}
```

### 2.4 REAL TEMPLATE ENGINE & DATA-PRESERVING MIGRATION

A template is not just an aesthetic theme; it is a complete, structured digital publication:
```
Template Definition
├── Metadata (Id, Name, Category, Tags, Author, Version)
├── Design Tokens (Typography scale, Color palette universes, Border styles)
├── Pages (Home, Our Story, Schedule, Gallery, RSVP, Contact)
├── Sections (Ordered list of section scene definitions)
├── Components (Master component definitions)
├── Assets (Bundled royalty-free assets)
├── Motion & Soundtracks
└── Responsive Breakpoint Rules
```

#### 2.4.1 Non-Destructive Template Migration Protocol
When switching templates:
1. **Extract Existing Data**: Reads existing `bindings` across all current nodes into a unified `ProjectContentMap`:
   ```typescript
   interface ProjectContentMap {
     celebrants: { person1: string; person2: string };
     event: { title: string; date: string; venue: string; address: string };
     story: { headline: string; paragraphs: string[] };
     media: { heroImage: string; gallery: string[] };
     rsvp: { enabled: boolean; questions: any[] };
     customFields: Record<string, any>;
   }
   ```
2. **Instantiate Target Blueprint**: Creates deep clone of the new template's SceneGraphs.
3. **Map Content into Target Slots**: For each node in the new template containing a `binding` key, automatically injects the corresponding extracted data.
4. **Transition Animation**: Canvas triggers a crossfade transition while preserving zoom level and artboard scroll position.

### 2.5 SECTION SYSTEM
Sections are the primary building blocks of modern responsive websites.
- **Section Structure**:
  - Artboard Frame (`kind: 'frame'`) with responsive height and width constraints.
  - Semantic HTML tag (`<header>`, `<section>`, `<footer>`).
  - Nav Anchor (`id="gallery"`, `id="rsvp"`) for auto-generated navigation.
  - Background surface (solid color, mesh gradient, video loop, or Three.js WebGL canvas).
- **Section Operations**:
  - `ADD_SECTION`: Appends or inserts a section at target index.
  - `MOVE_SECTION_UP` / `MOVE_SECTION_DOWN`: Reorders section order in both `scenes` and `activePage.sectionIds`.
  - `DUPLICATE_SECTION`: Deep clones section with regenerated unique IDs for all descendant nodes.
  - `REMOVE_SECTION`: Deletes section safely without corrupting project pages.
  - `SAVE_SECTION_AS_TEMPLATE`: Exports section to user's custom section library.

### 2.7 ASSET STUDIO & MEDIA MANAGEMENT
- **Upload Capabilities**: Direct file drag-and-drop, OS file picker, or clipboard paste. Supports PNG, JPG, WebP, SVG, MP4, WebM, Lottie JSON, and GLTF/GLB 3D models.
- **Processing**:
  - Automatically calculates dimensions and aspect ratio.
  - Generates lightweight preview thumbnails.
  - Stores assets in project registry with category tagging (Backgrounds, Photos, Logos, Music).
- **Direct Canvas Drop**:
  - Dropping on canvas background sets section background image.
  - Dropping onto an existing `image` node updates its source URL immediately while preserving node dimensions, corner radius, and styling.

### 2.8 INSPECTOR REDESIGN (CONTEXTUAL OBJECT INSPECTOR)

The right sidebar adapts dynamically based on selection state:

#### 1. Nothing Selected (Document & Page Inspector)
- Page Settings: Name, Slug, SEO Title, Meta Description, Social Share Image.

- Section Overview: Quick reorder and visibility toggles for all sections on current page.

#### 2. Text Selected
- Typography: Font family (Google Fonts integration), Size (px/rem), Weight (100–900), Line Height, Letter Spacing, Text Transform, Align (Left/Center/Right/Justify).
- Text Color: Interactive HSV/HEX/RGBA picker with document palette swatches.

#### 3. Image Selected
- Image Source: URL input, File Upload button, Asset Library selector.
- Object Fit: Cover, Contain, Fill.
- Border & Radius: 4-corner unlinked corner radius sliders.
- Image Filters: Brightness, Contrast, Grayscale, Sepia, Blur.

#### 4. Section / Container Selected
- Layout Controls: Direction (Row/Col), Align, Justify, Gap, Wrap.

- Background: Solid, Gradient (Linear/Radial), Video background, Canvas 3D background.
- Parallax Depth: Scroll velocity multiplier.

### 2.9 COMPONENT SYSTEM (FIGMA-GRADE MASTER & INSTANCES)
- **Master Component (`❖`)**: Converting any section or frame into a Component saves it to the project's Master Component Registry.
- **Instance (`◇`)**: Dragging a component into the canvas creates a lightweight instance.
  - Inherits layout, styling, and child hierarchy from master.
  - Supports isolated overrides (Text copy, Image source, Button link).
  - Shows visual "Reset Override" or "Push Changes to Master" buttons in inspector.

### 2.10 RESPONSIVE ENGINE (CASCADE INHERITANCE)
- Breakpoints:
  - **Desktop**: $1440\text{px}$ (Base breakpoint).
  - **Tablet**: $768\text{px}$.
  - **Mobile**: $390\text{px}$.
- **Inheritance Rule**: Values set on Desktop cascade down to Tablet and Mobile automatically.
- **Visual Override Flags**: Inspector highlights properties in blue/gold badge when overridden on the active breakpoint, allowing designers to clear overrides with one click.

### 2.12 AI DESIGNER ENGINE (DIRECT SCENEGRAPH MUTATIONS)
Unlike naive chatbots that return text explanations or unstyled HTML snippets, the OrbitoX AI Designer Engine modifies the living SceneGraph directly:
1. **Prompt Ingestion**: Receives user intent (e.g., *"Make this anniversary page feel like an Italian luxury editorial editorial with warm gold accents and serif headings"*).
2. **AST Mutation Plan**: Generates atomic commands:
   - `SET_DESIGN_TOKENS`: Replaces active palette with Tuscan Gold, Ivory, and Espresso; swaps typography to *Playfair Display* and *Cinzel*.
   - `UPDATE_NODE_STYLE`: Injects elegant 1px gold borders and refined letter spacing across all section headings.
   - `UPDATE_NODE_GEOMETRY`: Refines section padding and max-widths for editorial breathing room.
3. **Execution & History Snapshot**: Dispatches mutations through `TemplateEditorStore.dispatch()` as a single atomic history frame.
4. **Instant Visual Result**: Canvas reflects changes in real time. User can inspect every altered node or press `Cmd + Z` to revert.
